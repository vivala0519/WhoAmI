# 파티클 공

참고 채팅: Find tron.network banner 제작 방식 (01a0cf01-5282-7b71-84dd-40b2b277d60e). 해당 채팅에 요청해 기존 구현 원리를 확인했다. 기존 구현은 Three.js/WebGL의 구 표면 입자에 숨은 Canvas에서 읽은 PNG 픽셀 색을 투영하고, 모이기·분산·포인터 반응을 적용한다.

현재 헤더는 같은 이미지 색상 추출 원리를 Canvas 2D의 구 표면 투영에 적용한다. public/particle-ball.png는 사용자가 제공한 원본이다. 투명 영역을 제외하고 약 7,800개의 점을 만들며, 한 장의 사진에 보이는 무늬를 유지하며 화면을 향한 축으로 계속 회전하고, 다른 두 축으로는 작게 기울어진다. 사진에 없는 뒷면을 생성하지 않는다.

구현: src/ParticleBall.tsx, src/particle-ball.css. 처음에는 입자가 모여 공을 이루고 이후 연속 회전한다. 공을 터치하거나 클릭하면 250ms 동안 입자가 흩어지고, 터치 후 3초부터 900ms 동안 다시 모인다. 반복 터치는 현재 산개 상태를 유지하며 3초 대기 시간을 다시 시작한다. 짧은 탭만 인식해 스크롤과 버튼 조작에 간섭하지 않는다. 포인터 근처의 입자는 밀렸다가 복원된다. 밝은/어두운 테마에 맞춰 입자 명도를 조정한다. 렌더링은 최대 30fps·DPR 2이며, 화면 밖·숨긴 탭·표시 영역이 없는 상태에서는 중단한다. 동작 줄이기 설정에서는 정지된 공을 그린다. Canvas가 준비되지 않거나 실패하면 PNG를 표시한다.
