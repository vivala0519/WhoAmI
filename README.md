# WHO AM I? 한국어 에디션

React + TypeScript + Tailwind CSS 4 + Vite로 만든 독립 웹앱입니다.

```powershell
cd C:\Users\pc\IdeaProjects\copero\who-am-i
npm install
npm run dev
```

개발 주소: http://127.0.0.1:5175

```powershell
npm run build # TypeScript 검사 + 배포용 dist 생성
npm run preview
```

## 구현 범위

- 매일 1문제: 프리미어리그, 시장가치 약 45억 원 이상 선수 250명을 중복 없이 날짜별 배정
- 무제한: 수집한 세계 시장가치 상위 250명 중 무작위 선정
- 국적·구단·포지션·출생연도·등번호·시장가치 6개 항목, 5회 제한
- 초록: 정확히 일치 / 노랑: 같은 포지션 계열 / 빨강: 불일치
- 나이·등번호·시장가치는 정답을 기준으로 높음·낮음 화살표 표시
- 한국어·영문·초성 이름 검색, 키보드 선택, 중복 추측 제외
- 승리·실패·정답 공개·다음 문제·결과 공유·기록·게임 방법
- localStorage 진행 복원, 한국 시간 자정의 일일 문제 갱신
- 반응형 화면, 외부 이미지·폰트·런타임 API 호출 없는 플레이

## 데이터와 재현 범위

2026-10-29에 원본 공개 게임을 REA MCP로 조사했습니다. `docs/RESEARCH.md`에 확인 내용과 증거를 기록했습니다. 380명의 실재 선수 속성, 한국어 이름, 구단·국적·포지션을 로컬 스냅샷에 포함합니다. 정보는 수집일 기준이며 실시간 선수 이적·몸값을 반영하지 않습니다.

원본의 서버가 선정하는 **매일의 정답 자체**와 계정별 통계·전 세계 순위는 연동하지 않습니다. 일일 정답은 `src/daily-schedule.json`의 고정 일정으로 정하며 모든 사용자가 같은 날짜에 같은 선수를 받습니다. 2026-10-29부터 후보 250명을 무작위로 섞은 순서대로 하루에 한 명씩 배정하고, 250명을 모두 사용한 뒤 같은 순서로 다시 순환합니다. 따라서 연속한 250일 안에는 중복이 없으며 같은 선수는 250일 간격으로 다시 출제됩니다. 이미 공개된 2026-10-29·30·31일 정답은 유지합니다. 접속을 건너뛰어도 다음 접속일에 예정된 선수를 받습니다. 통계는 이 브라우저의 오늘의 챌린지만 집계하며 무제한 모드는 제외합니다. 평균 시도 횟수는 성공한 오늘의 챌린지의 시도 횟수 합계를 성공 횟수로 나눕니다. 실패·정답 공개·무제한 모드는 평균에서 제외하며, 성공한 기록이 없으면 —로 표시합니다. 이전 8회 규칙에서 성공한 기록도 포함합니다. 연승은 완료한 오늘의 챌린지를 연속으로 맞힌 횟수이며 미참여일에는 끊기지 않습니다. 이전 합산 통계는 별도 보존하고, 저장된 첫 번째 일일 결과가 완료된 경우에만 새 통계로 복구합니다. 원본 상표·로고·사진·문장·글꼴을 앱 자산으로 복제하지 않고, 게임 규칙과 사용자 흐름을 한국어로 다시 구현했습니다.

`scripts/capture-data.mjs`, `scripts/prepare-data.mjs`는 같은 작업 공간의 `whatsMyValue`에서 이미 수집한 공개 선수 ID와 한국어 표기를 참조하는 수집용 도구입니다. 일반 실행·빌드·테스트에는 이웃 프로젝트나 네트워크가 필요하지 않습니다. 완성된 앱 데이터는 `src/players.json`에 모두 들어 있습니다.

### 토스 전면 광고

무제한 모드에서 다음 선수로 넘어갈 때 미리 로드된 전면 광고가 있으면 표시합니다. 개발 서버에서는 토스 테스트 광고 ID를 사용하며, 프로덕션 빌드에는 콘솔의 전면 광고 그룹 ID를 `VITE_TOSS_INTERSTITIAL_AD_GROUP_ID` 환경변수로 설정하세요. 광고를 불러오지 못하거나 지원하지 않는 환경에서는 게임이 계속됩니다. 실제 광고 렌더링은 토스 앱에서 확인해야 합니다.

### 앱인토스 번들 빌드

`npm run build:toss`를 실행하면 웹 프로덕션 빌드 후 `whoami.ait` 번들을 생성합니다. 앱 식별자는 콘솔 등록값 `whoami`를 사용합니다.

오늘의 챌린지는 새로 결과가 나온 뒤 1초 후 준비된 전면 광고를 표시합니다. 완료된 기록 복원·모드 재진입 시에는 반복 표시하지 않습니다. 모드를 바꾸거나 화면을 떠나면 예약을 취소하며, 광고 미준비·미지원 환경에서는 결과 화면을 유지합니다.
